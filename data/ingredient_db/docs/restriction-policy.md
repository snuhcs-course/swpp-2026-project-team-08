## 핵심 요약

2. 모든 값은 **“이 재료가 해당 제한에 걸리는가?”**에 답한다. 제품 차이와 정보 부족을 구분한다.
3. 저과당·저염·케톤은 이름 기반 기준으로 분류하며 양이 필요하면 보류한다. 섭취량 평가와 제품 배합 확인은 별도로 한다.

## 1. 판정값

| 필드 | 값 | 뜻 |
|---|---|---|
| `review_status` | `DECIDED` / `UNRESOLVED` | 이름 기반 결정 / 보류. `relation=null`일 때만 보류 |

예: 밀가루 × `wheat` = `ALWAYS`, 감자 원물 × `wheat` = `NEVER`, 밀 배합 여부가 다른 간장 × `wheat` = `DEPENDS_ON_PRODUCT`.

영양량 제한에서 ALWAYS/NEVER는 아래 **고정 비교량에서 기준을 초과하는지**를 뜻한다. 모든 섭취량에서 금지/허용된다는 뜻은 아니다.

각 관계에 `ingredient_key`, `restriction_id`, `relation`, `review_status`, `reason`, `evidence`를 남긴다. `ingredient_key`는 현재 데이터셋에서 유일한 `kor_name`을 쓰고 DB 적재 때 ID로 바꾼다. `evidence`에는 원본 코드, 사용한 자료 위치, 확인한 사실을 기록한다. 보류에는 필요한 정보도 `reason`에 적는다.

## 2. 공통 규칙

- **이름이 정의하는 범위로 판정한다.** 원료·부위·명시된 배합을 함께 본다. 단순 가열로 알레르겐이 사라졌다고 처리하지 않는다.
- **미표기 ≠ 없음.** 원물의 정체나 전체 배합으로 비해당을 입증해야 `NEVER`다. 혼합품의 일부 원료만 보고 나머지를 없다고 추정하지 않는다.
- **제품 차이를 입증해야 `DEPENDS_ON_PRODUCT`다.** 배합·정제·인증에 따른 양쪽 사례나 명시적 제품군 정의를 근거로 남긴다. 단지 모르면 `UNRESOLVED`다.
- 알레르기·성분 존재 기반 제한은 한 원료라도 해당 성분이 확실하면 `ALWAYS`다. 희석·발효만으로 비해당 처리하지 않는다. 영양량 제한은 혼합 후 실제 함량으로 다시 계산한다.
- 원료 유래와 잔존 성분을 구분한다. 정제유·전분·가수분해물은 원료 이름만으로 알레르겐 잔존 여부를 확정하지 않는다. 정제 방식·제품 근거가 필요하다.
- 일반 교차접촉 가능성은 모든 재료를 제품별 차이로 바꾸는 근거로 쓰지 않는다. 특정 제품의 주의 문구는 별도 제품 정보다. `NEVER`는 교차접촉까지 확인한 안전 보증이 아니다.
- 귀리의 글루텐은 아래 별도 기준을 적용한다. 글루텐 제거 표시는 밀 알레르기 비해당의 근거로 쓰지 않는다.
- 추천 시 `ALWAYS`는 제외, `DEPENDS_ON_PRODUCT`·`UNRESOLVED`는 제품 확인 전 자동 추천에서 제외한다. `NEVER`만 해당 제한 검사를 통과한다.

## 4. 양·자료·첨가물 기준

### 4.1 이름 기반 분류

이 작업은 재료 이름·원본 이름에 명시된 원료와 가공 상태만 사용한다. 사용량, 100g당 함량, 가상 음식은 만들지 않는다. 아래는 앱의 정성적 재료 분류 기준이며 실제 섭취량의 허용 여부를 뜻하지 않는다.

| 제한 | ALWAYS: 이름으로 제한 대상 확인 | NEVER: 이름으로 비해당 확인 | UNRESOLVED |
|---|---|---|---|
| 저과당 | 과당·설탕·꿀·과당 함유 시럽처럼 과당 또는 자당을 공급하는 감미 재료 | 첨가 없는 순수 기름·소금·물 | 과일·채소·혼합품 등 함량과 양이 있어야 판단 가능한 재료 |
| 저염 | 소금 및 이름에 소금 첨가·염장·소금절임이 명시된 재료 | 순수 물·기름·설탕 | 자연 나트륨 함량이나 제품 배합 확인이 필요한 나머지 재료. 저염 표시만으로 NEVER 금지 |
| 케톤 | 설탕·전분·곡물가루처럼 당·전분이 주성분인 재료 | 첨가 없는 순수 기름·소금·물 | 탄수화물 함량·섭취량이 필요한 나머지 재료 |

이름이 위 범주에 명확히 속하지 않으면 유추하여 확정하지 않는다. 제품별 차이가 제공된 근거로 확인될 때만 DEPENDS_ON_PRODUCT다. 단순히 양을 모르는 경우에는 null을 사용한다. 모든 제한의 상태는 DECIDED 또는 UNRESOLVED이며 nutrition_estimate는 요구하거나 생성하지 않는다.

### 4.2 이전 결과와 구분

정책 버전은 restriction-policy-1.6이다. 이전의 2g·140mg·5g 추정 기여량 기준과 ESTIMATED 결과는 이 실행에 사용하지 않는다. 새 실행 폴더를 만들고 이전 결과를 자동으로 가져오지 않는다.

### 4.4 첨가당과 지정 첨가물

`no-added-sugar`는 **첨가당 없음 AND 아래 지정 첨가물 없음**으로 정의한다. 첨가물의 유해성·합법성을 판정하는 목록이 아니라 앱의 선호 필터다. 양에 따른 면제 없이 원재료표에서 확인된 첨가를 대상으로 한다.

**첨가당:** 설탕·자당·포도당·과당·맥아당 등 첨가용 당, 꿀·물엿·시럽·조청·당밀, 감미 목적으로 더한 농축 과즙. 이 감미 재료 자체도 해당한다. 우유·과일 원물의 본래 당은 해당하지 않는다. “무설탕”만으로 아래 첨가물까지 없다고 판단하지 않는다.

**지정 첨가물 v1 — 다음 목록만 사용한다.** 성분의 한영 동의어·INS/E번호는 동일 성분으로 정규화하며 번호가 있는 모든 첨가물을 금지하지 않는다.

| 군 | 대상 목록 |
|---|---|
| 합성 착색료 | 타르트라진(102), 퀴놀린옐로(104), 선셋옐로FCF(110), 아조루빈/카르모이신(122), 아마란스(123), 폰소4R(124), 에리트로신(127), 알루라레드AC(129), 인디고카민(132), 브릴리언트블루FCF(133), 패스트그린FCF(143). 이 성분의 알루미늄 레이크 포함 |
| 합성 고감미료 | 아세설팜칼륨(950), 아스파탐(951), 사이클라메이트류(952), 사카린류(954), 수크랄로스(955), 네오탐(961), 어드밴탐(969) |
| 지정 보존료 | 소르빈산·소르빈산염(200–203), 벤조산·벤조산염(210–213), 아질산염·질산염(249–252), 프로피온산·프로피온산염(280–283) |
| 지정 산화방지제 | TBHQ(319), BHA(320), BHT(321) |
| 합성 향료 | 원재료표에 “합성향료” 또는 “artificial flavor(s)”로 명시된 첨가. 단순 “향료/flavoring”은 종류 확인 전 보류 |

- 비타민·미네랄 강화, 레시틴·펙틴·한천·젤라틴·구연산·베이킹파우더·이스트·MSG·스테비올배당체·에리스리톨은 **이 목록에 없다는 이유로 이 필터에서 자동 금지하지 않는다.** 별도 제한은 독립 판정한다.
- 천연색소·천연향료는 이 목록의 대상이 아니다. 단, 함께 들어간 첨가당·지정 성분은 별도로 확인한다.
- 일반 “보존료”, “착색료”, 불명확한 복합첨가물은 세부 원료 확인 전 보류한다. “무첨가”라는 홍보 문구만으로 원재료표 확인을 대신하지 않는다.
- 첨가당 또는 지정 첨가물 중 **하나라도 확인되면 ALWAYS**. 둘 다 없다는 근거가 있으면 NEVER. 같은 이름의 배합에 양쪽 사례가 확인되면 제품별 차이, 나머지는 보류다.

## 5. 근거와 적용 범위

**고정 목록의 근거:** `ChoiceStepView.tsx`에서 `MultiChoice.options`로 전달하는 `allergies`, `restrictions`, `approaches` 기본 버튼이다. `catalogOptions`는 Other 검색 후보이며 고정 restriction에서 제외한다. `none`·자유 입력도 제외한다.

API 대응은 알레르기 → `safety.allergies.items`, 식이 제한 → `safety.restrictions.items`, 식단 방식 → `food_preferences.dietary_approaches`다. `onboardingApi.ts`는 검색 후보도 code로 전송할 수 있지만, 이를 고정 restriction으로 자동 추가하지 않는다. 검색 입력을 실제 재료·기타 제한으로 해석하는 처리는 별도 작업이다.

이 문서는 법정 알레르겐 목록을 그대로 복사한 것이 아니라 기존 앱의 17개 ID를 위한 분류 정책이다. 견과 목록, 달걀 범위, 갑각류 범위는 위 표로 명시한다.

- [FDA 식품 알레르기 안내](https://www.fda.gov/food/nutrition-food-labeling-and-critical-foods/food-allergies): 알레르겐과 원료 표시 참고.
- [FDA 알레르겐 표시 지침](https://www.fda.gov/regulatory-information/search-fda-guidance-documents/guidance-industry-questions-and-answers-regarding-food-allergen-labeling-edition-5): 가공·표시 관련 참고. 표시 면제가 곧 무알레르겐이라는 뜻은 아님.
- [FDA 글루텐 프리 기준](https://www.fda.gov/food/nutrition-food-labeling-and-critical-foods/questions-and-answers-gluten-free-food-labeling-final-rule): 20 ppm 미만과 귀리·원료 조건 참고.
- [NIDDK 유당 제한 안내](https://www.niddk.nih.gov/health-information/digestive-diseases/lactose-intolerance/eating-diet-nutrition): 유당 저감·무유당 제품 구분과 개인별 허용량 차이 참고.

이번 작업은 분류 기준 작성까지다. 관계 27,081개와 서버의 실제 수치·성분 판정 코드는 아직 생성하지 않았다. 기준 변경 시 `policy_version`을 올리고 변경된 관계를 다시 판정한다.

추가 근거:

- [FDA 나트륨 안내](https://www.fda.gov/food/nutrition-education-resources-materials/sodium-your-diet): 표시섭취량과 140mg 안내. 현재 이름 기반 분류에는 수치 경계를 적용하지 않는다.
- [Monash 과당·포도당 설명](https://www.monashfodmap.com/blog/the-facts-about-glucose-and-fructose/): 저FODMAP과 총과당 분류를 구분하는 근거. 현재 분류에는 2g 기준을 사용하지 않는다.
- [Charlie Foundation 케톤 식이](https://charliefoundation.org/diet-plans/): 식이 유형과 지방 대 단백질·탄수화물 비율 참고. 현재 분류에는 5g 기준을 사용하지 않는다.
- [FDA 첨가당 정의](https://www.fda.gov/food/nutrition-food-labeling-and-critical-foods/industry-resources-changes-nutrition-facts-label): 꿀·시럽·감미용 농축 과즙 구분 참고.
- [FDA 감미료 안내](https://www.fda.gov/food/food-additives-petitions/aspartame-and-other-sweeteners-food), [FDA 착색료 안내](https://www.fda.gov/food/color-additives-information-consumers/color-additives-foods): 성분 식별 참고. 위 지정 목록은 앱 정책이며 특정 국가의 허용·금지 목록을 뜻하지 않는다.

## 실행 후 AI 검토

1.6 기준으로 생성한 결과에 일반 식품군·일반 사용 가정 검토를 추가했다. 구체적인 적용과 예외는 [통합 검토 안내](../../ingredient_restrictions/README.md#검토-결과-v1), 각 행의 이유는 최신 결과와 decisions.json에 보존한다. 이 추가 판단은 기존 API 실행 기준과 구분하며 함량 측정값을 생성하지 않는다.
