# 재료와 제한 판정

목차: [재료](#재료) · [이름](#이름) · [제한](#제한) · [다수결](#다수결) · [Astra 검토](#astra-검토)

재료는 장보기와 조리에 사용하는 원물 또는 가공 원료다.
제한 판정은 재료의 원료와 명시된 배합을 기준으로 한다.
Gemini A·B·C의 유효한 응답 중 두 개가 같은 판단이면 채택한다.

정책 버전: `3`. 입력은 USDA FoodData Central의 SR Legacy 2018 최종판이다.
다른 데이터셋의 재료를 추가하거나 원문에 없는 배합을 만들어내지 않는다.

## 재료

각 원본은 `INCLUDE`, `EXCLUDE`, `UNKNOWN` 중 하나와 짧은 이유를 갖는다.
전체 이름과 식품군을 함께 읽는다. 첫 쉼표 앞 단어나 식품군만으로 분류하지 않는다.

| 포함 | 예시와 경계 |
|---|---|
| 식용 원물과 부위 | 채소, 과일, 곡물, 콩, 견과, 씨앗, 버섯, 육류, 생선, 알, 내장 |
| 원물을 가공한 조리 재료 | 가루, 전분, 오트밀, 무양념 면·반죽, 두부, 템페, 건과일, 원료 통조림 |
| 우유와 조리용 유제품·대체품 | 우유, 플레인 요구르트, 치즈, 크림, 버터, 조리용 분유, 무가당 대체유 |
| 양념과 감미 재료 | 기름, 소금, 향신료, 허브, 설탕, 꿀, 시럽, 잼, 코코아, 순수 초콜릿 |
| 제빵·제과 재료 | 효모, 베이킹파우더·베이킹소다, 크림 오브 타르타르, 펙틴, 식품용 젤라틴·한천, 빵가루 |
| 조리용 배합 재료 | 브랜드 없는 조리용 소스·드레싱 제품, 육수, 견과 버터, 일반 베이킹 믹스, 피클 |
| 음식에 넣는 기본 빵·보존육 | 속·토핑 없는 식빵·바게트·또띠아·베이글·롤·난, 햄·베이컨·소시지 |
| 물과 조미용 원료 | 무향 물, 마른 차·커피 원료, 무가당 레몬즙·라임즙, 명시된 cooking wine |

완성 식사·반찬·수프, 양념과 결합한 메뉴, 튀김옷을 입힌 제품, 간식·디저트,
시리얼, 완성 음료, 일반 음용 주류, 영아용 조제식·보충제는 제외한다.
브랜드·식당 전용 제품도 제외한다. 위 표에 속하는 일반 재료만 포함한다.
우유는 음료 제외의 예외이며, 육수는 건더기 있는 완성 수프와 구별한다.
식품용 첨가물도 실제 조리 원료이면 포함한다. 펙틴·레시틴·스테비아 감미료가 이에 해당한다.
일반 어유 원료는 포함하고, 섭취용 캡슐 등 완성 보충제는 제외한다.
보존 과일·토핑·농축 과즙과 기본 건조 빵은 조리 재료로 포함한다.
포함할 종류나 명시된 배합을 원문으로 식별할 수 없으면 `UNKNOWN`이다.
낯설거나 드물다는 이유로 원물을 제외하지 않는다.

### 소스와 드레싱

- 브랜드 없는 케첩·마요네즈·간장 등 조미 제품과 병입 드레싱은 조리에 넣는 재료로 포함한다.
- `prepared from recipe`, `homemade`, `home-prepared`·`home prepared`·`home recipe`·`prepared-from-recipe`처럼 레시피로 만든 복합 음식은 제외한다.
  이 규칙은 모든 포함 종류보다 우선하며 레시피 치즈 소스·수제 육수·레시피 빵·수제 면에도 적용한다.
  `Cheese sauce, prepared from recipe`는 제외한다. 이름에서 조리 설명을 지워 재료로 바꾸지 않는다.
- `prepared` 한 단어만으로 제외하지 않는다. 원물의 단순 가열과 제품의 사용 준비는 레시피 음식과 구별한다.
- 소스·드레싱이라는 이름만으로 포함하지 않는다. 장보기 재료인지 레시피 음식인지 구별할 근거가 없으면 `UNKNOWN`이다.
- 일반 딥·스프레드·후무스는 음식에 넣는 조미 재료로 포함한다. 완성 샌드위치·디저트는 제외한다.
- 브랜드 제품 제외가 소스·드레싱 포함보다 우선한다.
  포함 제품은 근거가 부족한 제한만 `UNKNOWN`으로 보류하며, 확인된 제품별 차이는 `DEPENDS_ON_PRODUCT`로 판정한다.

## 이름

- 미국식 영어의 짧은 일반명을 쓴다. 첫 글자는 대문자이며, 원본 색인·브랜드·품질 등급을 넣지 않는다.
- 같은 원료의 품종·등급·산지·단순 가열·해동·절단 형태는 합친다.
- 원료, 독립적인 식용 부위, 조리에 넣는 형태, 보존 방식, 명시된 배합 차이는 남긴다.
  `Wheat flour`와 `Rice flour`, `Egg white`와 `Egg yolk`, `Milk`와 `Lactose-free milk`는 다르다.
- 고기의 부위는 남기되 같은 부위의 지방 손질·등급·조리 온도 차이는 합친다.
- 생과일과 건과일, 원물과 기름·가루·전분, 생선과 훈제 생선은 다르다.
- 원문이 원료 첨가를 명시하면 이름에도 구분한다. 표기가 없다고 무첨가로 해석하지 않는다.
- 합칠 때 원본 ID 집합과 이름이 모두 두 표 이상 일치해야 한다. 같은 이름만으로 합치지 않는다.
- 비교할 때 NFC, 앞뒤·연속 공백, 대소문자만 정리한다. 유사 문자열이나 단복수 추측으로 합치지 않는다.
  이름을 확정하지 못한 원본은 최종 목록에서 보류한다.

## 제한

모든 재료는 아래 19개 제한을 각각 판단한다. 값과 서버의 `RestrictionType`은 같아야 한다.
`ALLERGY.NONE`은 판정 대상이 아니다. `VEGETARIAN`은 채식 유형 이름이 아니라 피할 원료군이다.

| restriction_type | 제한에 해당하는 원료·성분 |
|---|---|
| ALLERGY.PEANUTS | 땅콩 및 땅콩 단백질이 남는 원료 |
| ALLERGY.TREE_NUTS | 아몬드·호두·캐슈 등 나무 견과 및 그 단백질 |
| ALLERGY.MILK_DAIRY | 포유류 우유의 단백질; 유당 제거만으로 해제하지 않음 |
| ALLERGY.EGGS | 조류의 알과 알 단백질 |
| ALLERGY.SOY | 대두 및 대두 단백질이 남는 원료 |
| ALLERGY.WHEAT | 밀 및 밀 단백질; 글루텐 여부와 별도로 판단 |

| VEGETARIAN.SEAFOOD | 생선·갑각류·연체류에서 유래한 재료; 해조류 제외 |
| VEGETARIAN.POULTRY | 닭·칠면조 등 조류의 고기·내장·지방·육수; 알 제외 |

| VEGETARIAN.LEGUMES_SOY | 콩과 식물과 그 유래 원료; 대두·완두·렌틸·땅콩 포함 |
| VEGETARIAN.NUTS_SEEDS | 견과·식용 씨앗과 그 유래 원료; 곡물·콩류는 이 항목에서 제외 |
| DIETARY_APPROACH.GLUTEN_FREE | 밀·보리·호밀 계열 글루텐 |
| DIETARY_APPROACH.CASEIN_FREE | 우유 단백질인 카세인 |
| DIETARY_APPROACH.LACTOSE_FREE | 유당; 우유 알레르기·카세인 제한과 별도로 판단 |

| degree | 의미 |
|---|---|
| NEVER | 명확한 재료 정체성과 배합에 해당 제한 원료·성분이 없음 |
| ALWAYS | 재료의 정의상 해당 제한 원료·성분을 포함함 |
| DEPENDS_ON_PRODUCT | 같은 일반명에서도 실제 제품의 배합·가공에 따라 달라짐 |
| UNKNOWN | 원료·가공·성분을 판단할 근거가 부족함 |

영양성분 값의 누락·반올림된 0이나 알레르겐 표기의 부재를 `NEVER`의 근거로 쓰지 않는다.
일반적인 단일 원물의 정체성은 근거로 사용할 수 있다. 알 수 없는 배합은 추측하지 않는다.
고도로 정제된 기름과 단백질이 남는 기름, 젤라틴의 동물 원료, 유청의 카세인 잔류처럼
가공·원료 확인이 필요한 경우에는 명시된 사실로 판정하고, 확인할 수 없으면 보류한다.
소량이면 괜찮다는 섭취량 기준이나 질환 치료 효과는 판정에 넣지 않는다.
제품별 인증·교차접촉·개인별 반응은 이 자료의 판정 범위가 아니다.

기준 사례: `Rice`의 밀·글루텐 제한은 `NEVER`, `Wheat flour`는 두 제한 모두 `ALWAYS`다.
`Milk`는 유제품·우유 알레르기·카세인·유당 제한에 `ALWAYS`다.
명시된 `Lactose-free milk`는 유당에 `NEVER`지만 우유 알레르기와 카세인에는 `ALWAYS`다.
일반 `Bread`의 달걀 배합은 `DEPENDS_ON_PRODUCT`이며, 해당 원문이 배합을 명시하면 그 사실을 따른다.

## 다수결

A·B·C는 같은 원본과 정책을 받고 다른 응답을 보지 않는다. 재시도는 같은 슬롯을 대체한다.
세 유효 응답이 모두 있어야 작업을 마친다. 두 표가 같은 값이면 반대 한 표와 관계없이 채택한다.
재료 포함 여부, 이름·묶음, 제한 정도는 각각 합의해야 한다.
`UNKNOWN` 다수 또는 세 판단이 다른 경우는 보류하며 네 번째 판정자로 덮어쓰지 않는다.
형식 오류·누락·중복·통신 실패는 표가 아니다. 실패한 슬롯만 다시 실행한다.
확정 재료에는 이름순 정수 ID를 부여한다. 제한 보류는 결과 JSONL에서 행을 생략한다.


## Astra 검토

Astra는 Gemini의 네 번째 투표자가 아니라 정책 준수 검토자다.
소스·드레싱, 레시피 음식, 브랜드 제품의 포함 결과와 세 응답이 갈린 사례를 원문과 함께 검토한다.
세 응답이 모두 같은 항목도 경계 사례이면 검토한다. 세 모델이 같은 정책 위반을 할 수 있다.
검토 기록에는 원본 ID·원문·Gemini 판정·위반한 기준·Astra의 판단 근거를 남긴다.
정책 위반이 확인된 항목은 최종 출력 전에 해결한다. 원래 표를 고치거나 네 번째 표로 뒤집지 않는다.
사용자가 검토 확정을 위임하면 원본별 포함·제외와 이름을 별도 검토 결정으로 기록한다.
검토 결정은 원래 세 표를 수정하지 않으며 다수결 결과로 표시하지 않는다.
새 정책의 실행은 기존 선정 표와 그 출처를 가져오고, 확정된 검토 결정을 적용한 뒤 이름·묶음을 판정한다.
검토로 포함한 원본은 단독 후보여도 이름을 세 에이전트에게 다시 확인한다.
해결되지 않은 검토 항목은 출시를 막는다.
Astra 검토는 데이터의 사실 확인이나 알레르기 안전 보증을 대신하지 않는다.
